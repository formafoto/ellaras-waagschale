# Ellaras Waagschale

Eine kleine Entscheidungshilfe: Frage eingeben oder ansagen, Punkte fuer beide
Seiten einsprechen, die Waage zaehlt und zeigt, wohin es kippt.

- Zwei Fragetypen: "Ja oder Nein" und "Zwei Moeglichkeiten" (A gegen B)
- Spracheingabe ueber die Web Speech API des Browsers (Chrome, Edge, Safari)
- Tippen als gleichwertige Alternative, inklusive Tastatur-Diktat
- Alle Eintraege bleiben lokal im Browser (localStorage), nichts wird gesendet
- Hell/Dunkel-Modus, fuer das Handy gebaut, "Zum Home-Bildschirm" moeglich

Statische Seite ohne Build-Schritt: index.html, Manifest und zwei Icons.
